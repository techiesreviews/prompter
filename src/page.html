Use your AI

Prompter has an open MCP server. Connect it to your AI assistant, then ask: “Help me write a prompter script about …”. It interviews you, writes and checks the script, and gives you a link that opens here.

https://prompter.techies.tools/mcp

  • Claude (claude.ai, Claude Desktop): Settings → Connectors → Add custom connector. Name it Prompter and paste the address.
  • ChatGPT: Settings → Apps & Connectors → Advanced settings → turn on Developer mode. Then create a connector with the address and No authentication. Menu names can differ a little.
  • Codex and T3 Code: add this to ~/.codex/config.toml (T3 Code uses your Codex and Claude Code settings): 
    [mcp_servers.prompter]
url = "https://prompter.techies.tools/mcp"
  • Claude Code: claude mcp add --transport http prompter https://prompter.techies.tools/mcp

No sign-in. Your script travels only inside the link. To stop heavy use, the server allows 60 requests a minute (10 per 10 seconds) per internet address. It counts them in memory only, under a hashed form of your address, never with your script, and forgets the count within a few minutes of your last request.
