Prompter

A free teleprompter for talking to camera. Big text, auto-scroll, and a second window that shows your links. Your script never leaves your device.

Or drop a .md or .txt file anywhere on this page.

How it works

  1. Write your script as plain text in the simple format below, or let your AI write it for you.
  2. Open it here. Put this window on the screen next to your camera.
  3. Click Connect main screen and drag the new window to your main screen. When you reach a section, its first link opens there. Press 1–9 to show its other links.
  4. Scroll with the mouse or arrow keys, or press Space to auto-scroll. Read the line at the dashed mark.

Your script stays with you

There are no accounts and nothing is saved on our server. A shared prompter link carries the whole script inside the link itself, in the part after #, which your browser never sends to any server. This browser remembers your last script so you can continue later. You can also save this page and use it offline.

Let your AI write the script

Prompter has an open MCP server. Connect it to your AI assistant, then ask: “Help me write a prompter script about …”. It will interview you, write the script, check it and give you a link that opens here.

Server address: https://prompter.techies.tools/mcp · no sign-in needed.

To stop heavy use, the server allows 60 requests a minute (10 per 10 seconds) per internet address. It keeps only a count, in memory, under a scrambled form of your IP address, and forgets it once you pause for a few seconds. Your script is not part of it, and nothing is written down.

Claude (claude.ai and Claude Desktop)

Settings → Connectors → Add custom connector. Name: Prompter. URL: the server address above.

Claude Code

claude mcp add --transport http prompter https://prompter.techies.tools/mcp

ChatGPT

Settings → Apps & Connectors → Advanced settings → turn on Developer mode. Then create a connector: name Prompter, the server address above, authentication No authentication. Menu names can differ a little between versions.

Codex and T3 Code

Add to ~/.codex/config.toml. T3 Code uses your Codex and Claude Code settings, so add it there.

[mcp_servers.prompter]
url = "https://prompter.techies.tools/mcp"

Other MCP apps (JSON config)

{
  "mcpServers": {
    "prompter": { "type": "http", "url": "https://prompter.techies.tools/mcp" }
  }
}
