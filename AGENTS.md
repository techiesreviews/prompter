# techies-prompter

Public teleprompter at https://prompter.techies.tools plus an open, stateless MCP endpoint at `/mcp`. Owner: Lex (non-technical; explain in plain words).

## Rules

- Agent Kit is required for all coding: read `docs/agents/agent-scripts.md`, run `scripts/agents/kit --help` and `kit doctor` first, then `kit specs` (and `kit shots`, `kit size` for page changes). Delegated work must carry this requirement.
- Scripts stay on the user's device. Never add server-side storage (KV, D1, R2, Durable Object storage, Cache API for scripts) or logging of request bodies. Keep `observability` off. Scripts travel in the URL fragment `#s=`; the only other way is the user's own agent through the live relay below, in memory only.
- Two exceptions, both Durable Objects that keep no script and log nothing:
  - The `/mcp` rate limiter in `src/limiter.mjs`: one object per hashed client (salted SHA-256 of the IP, never the raw IP) that counts requests in memory only. It must never use `ctx.storage`, receive a request body, or log.
  - The live relay in `src/relay.mjs` (approved by Lex, 2026-10-28), as in the script editor: one object per hashed agent token (`src/token.mjs`; salted SHA-256, never the token). Its storage holds only the note `{ createdAt, expiresAt, revoked, agent: { name, version } }`, which an alarm just after `expiresAt` (8 hours after the token's birth) erases; never script text. Scripts sent by the user's own agent (`show_script`) and the open script the agent reads (`get_open_script`) pass through it in memory only and are never stored or logged. Disconnect MCP marks the note revoked, so the token gets 401 until the alarm erases it.
  - Only `/mcp` may call the limiter. Only `/mcp` and `/api/*` (`/api/agent-token`, `/api/relay`, each with an in-memory per-client guard) touch the relay.
- Cloudflare free plan only. No paid features.
- `src/core.mjs` is the single source of truth for the format, presets ("lex" and "default"), checker, link encoding and the demo script. The page inlines it (and `src/follow.mjs`, the voice-follow line matching, `src/agent.mjs`, the Wait for MCP / Copy MCP messages and the agent's shown name, and `src/ui/range-field.mjs` with its `src/ui/range-field.css`, the reusable slider) at build time, so all four scripts must stay import-free and use only `export function`/`export const` forms.
- Follow my voice uses the browser's own speech recognition (Web Speech API) and is opt-in after a notice that the browser sends audio to its speech service. The page itself never sends audio anywhere, and sends the script only to the user's own connected agent when it asks (`get_open_script`). The page's `Permissions-Policy` allows the microphone for this origin only.
- Design: the Techies Reviews dark palette (indigo night page, bright orange actions), Inter and Roboto Mono. The plain address shows a start screen (never opens a script by itself); a script reads left-aligned in a centred column. No sidebar: one floating control bar (Open, previous, play, next, clock, Settings) with Open and Settings popovers (native Popover API, CSS anchor positioning with a script fallback). The Open popover holds the agent block (Wait for MCP, as in the script editor); the Open button shows only a small status dot for it. Settings: text size and scroll speed (range fields, `src/ui/`: one 44px box with the name inside, an indigo fill up to a white grip, faint ticks, and the value on the right that can be typed exactly, also past the slider's ends), width, then two big icon buttons side by side, about as tall as the control bar: Follow my voice (microphone; only with the speech API, otherwise the main screen's button takes the whole row) and Main screen (monitor; Connect / Reconnect), icons only (names for screen readers and a hover title), on the same quiet indigo button: the icon is a quiet outline when off and orange and filled when on; the Settings button shows a small dot while voice is on or a main screen is connected. While Follow my voice is on, the line being read is pure white (`--text-now`) and the lines after it in its section a little dimmer (`--upcoming`, still AA), with no box or underline; it follows word by word and line by line (`src/follow.mjs`): a single word or a pair of common words from a later line never moves it. No status messages appear on screen: the status line is for screen readers only (visually hidden). Copy feedback (Wait for MCP, Copy link) lives on the button itself (label and check); Copy link's spoken confirmation goes through the hidden status line. Text colours must meet WCAG AA (4.5:1) on their backgrounds; white on orange only at 19px bold (large text). `test/contrast.test.mjs` checks the `oklch()` tokens in `src/page.html`.
- The reading line can be dragged to camera height (remembered per device), and text above it is deliberately faded below WCAG AA (`--read-veil`) because it has been read. This is the one deliberate exception to the AA rule; do not raise it. `test/contrast.test.mjs` checks that it stays low.
- The built page must stay one self-contained HTML file that works offline (no external scripts, styles or fetches). Its only calls go to its own site for the live connection (`/api/agent-token` and the `/api/relay` WebSocket; CSP `connect-src 'self' wss://prompter.techies.tools`); a file:// copy has no relay and its Copy MCP copies the open server's message. The only extra files are the two fonts in `fonts/` (SIL OFL 1.1, licence in `fonts/OFL.txt`), served from `/fonts/` (CSP `font-src 'self'`); the page adds their `@font-face` only when served over http(s), so a file:// copy uses system fonts.
- CSS: simple, low-specificity, shared helpers first; bounded component overrides with `@scope` only where losing them is harmless. Respect `prefers-reduced-motion`. Keep mobile usable.
- Review with `kit review` (Claude only). Do not run GPT/Codex reviews.
- Do not deploy, push or change Cloudflare resources unless the lead says so.
