# Agent Kit (techies-prompter)

Agent Kit is required for all coding in this repo, for every model and provider, including delegated workers. Run `scripts/agents/kit --help`, then each relevant command's `--help`, and `kit doctor` before implementing. After changes run `kit specs`, and `kit shots` and `kit size` when the page changes. Every command ends with one `RESULT: ok|fail …` line naming its evidence folder.

The dispatcher, shared helpers (`kit-lib.sh`, `kit-lib.mjs`), `wait`, `version`, the review runner (`agent-run.mjs`, `review-brief.mjs`, and its process supervisor `sol-run.mjs`, a generic job runner despite the name) and `ci-summary.mjs` are copied from the static-site kit in `/home/ubulex/Projects/techies-reviews/scripts/agents` (itself from native-site-editor `origin/dev`). The main root is adapted to this repo, and review is pinned to Claude. `agent-run.mjs` also differs from that copy: it accepts small `claude-*` helper models (each at most a tenth of the pinned model's output), so keep that change when re-copying. `doctor`, `specs`, `shots` and `size` are this project's adapters in `scripts/agents/prompter-kit.mjs`.

Maintainer defaults below point to Lex's own folders; contributors override them with environment variables (`KIT_MAIN_ROOT` for the main checkout, `KIT_PLAYWRIGHT_MODULE` for Playwright). Browser tooling is external and never installed here: `KIT_PLAYWRIGHT_MODULE` may point to Playwright's `index.mjs`; default `/home/ubulex/Projects/native-site-editor-dev/node_modules/playwright/index.mjs`, with Chromium installed for that version. Wrangler must already be cached (`npx --no-install --package wrangler`). Tests start and stop their own servers on free localhost ports.

`.scratch/`, `dist/` and `.wrangler/` are git-ignored. Only `dist/` (built by `node scripts/build.mjs`) is uploaded as static assets.

## Deploy (lead-authorized only)

Deploy is not a kit command. With explicit authorization: `node scripts/build.mjs && npx --no-install --package wrangler wrangler deploy`. It deploys only the `techies-prompter` Worker with the custom domain `prompter.techies.tools`. Never touch other Workers (for example `lex-prompter`), routes or domains.
